# Assets Folder

This folder should contain the following images for the homepage:

## Required Images

1. **elevenlabs-demo.gif** (or .mp4)
   - Demo video/GIF showing the robot having a conversation
   - Recommended size: 800x600px or similar
   - Shows the robot responding to voice commands

2. **robot-icon.png**
   - Icon/logo for the hero section
   - Recommended size: 60x60px
   - Can be a Reachy Mini icon or custom logo

3. **robot-conversation.jpg**
   - Photo of Reachy Mini in conversation mode
   - Recommended size: 600x800px
   - Shows the robot's face/upper body

## Optional Images

You can add more images to enhance the page:
- Screenshots of the settings UI
- Photos of different use cases
- Team photos for the About section

## Placeholder Images

Until you have real images, you can:
1. Use placeholder images from https://placehold.co/
2. Record a quick demo video
3. Take photos of your Reachy Mini

## Image Optimization

- Compress images to reduce file size
- Use WebP format for better performance
- Keep GIFs under 5MB if possible
